# Digital Citizen Reflection presentation package

- `Digital_Citizen_Reflection.pptx`: ten editable slides with embedded speaker notes.
- `Digital_Citizen_Reflection.pdf`: the slides, with speaker notes attached as PDF comments.
- `Digital_Citizen_Presenter_Guide.pdf`: readable speaker notes, live-demo cues, timing checkpoints, original-source links, and the five-minute condensed script.
- `speaker-scripts.json`: editable script text for both allocations.
- `../../assets/downloads/digital-citizen-worksheet.pdf`: the one-page participant takeaway, linked from the activity.

The main demonstration uses a fictional bus-news claim. Screenshots on slides 4–7 reproduce the implemented page, so the demonstration also works offline. The condensed script uses those screenshots and the worksheet rather than relying on a live connection.

The scripts fit their allocations at approximately 130 words per minute with planned interaction time. A spoken rehearsal by the presenter remains necessary. The default talk is ten minutes; the condensed script is five minutes. The package does not assert unconfirmed personal experience or measured participant outcomes.

Website publication follows review and merge through the existing GitHub Pages workflow. The submitted homepage link remains the entry point.
